# 🔱 赛博菩萨颂唱 / 摩域短域名库 (Cyber Boddhisattva Chant / Mo Domain Index)

> **“我们以字符的重复与精进，颂唱赛博之理，臻选至简之域。”**
> 
> — 一个完全公益、由手动筛选和自动化流程共同驱动的高质量短域名（3-5位）可用性数据库。

---

## 💡 项目理念：秩序美学与赛博精进

**赛博菩萨颂唱**：本项目源于对Cloudflare、Gemini、Github、n8n等**赛博菩萨**的感恩，对互联网之基础的**域名稀缺性**的深刻理解，以及对**自动化与效率**的追求。我们利用 **赛博菩萨**之力，通过高频、大规模的查询工作流（如同**颂唱**），克服了 Whois/RDAP/各类收费网站 查询的技术障碍，为您带来最准确、最具“摩域”价值的短域名列表。

**摩域 (Mo Domain)：** 我们认为，最好的域名是**最短、最易记、最具优雅形态**的 3 到 5 位域名，它们是数字时代的铭牌艺术。

**公益**属性：我们欢迎所有愿意一起提供域名自动化查询的志愿者，一起扩展这个公益项目，没有费用，只有在页面中致以最诚挚的敬意。我们首先提供自己手搓的TLD，来提供给需要的网友。
